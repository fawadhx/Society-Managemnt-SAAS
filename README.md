# Society Manager — Property & Maintenance Management SaaS

Society Manager is a modern, responsive B2B SaaS platform designed for housing societies and commercial plazas. It simplifies maintenance fee tracking, automated billing, payment recording, and resident payment reminders with a 3-tier subscription model.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescript.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) & [shadcn/ui](https://ui.shadcn.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **State Management:** React Context API
- **Database & Backend:** [Supabase](https://supabase.com/) (PostgreSQL with Row-Level Security)

## 🎯 Key Features

- **3-Tier Subscription Model:**
  - **Tier 1 (Basic - PKR 1,500/mo):** Unit directory, manual collection ledger, manual SMS logs.
  - **Tier 2 (Pro - PKR 3,000/mo):** Batch invoice generation, WhatsApp reminder automation, advanced collection reports.
  - **Tier 3 (Enterprise - PKR 5,000/mo):** Multi-society management, append-only security audit logs, custom branding.
- **Interactive Modals:** Record payments, batch generate invoices, switch active societies, and edit admin profile settings in real-time.
- **Collapsible Sidebar Rail:** Modern Gemini/ChatGPT-style collapsible navigation rail with hover tooltips.
- **Local Fallback & DB Persistence:** Functions seamlessly with local state or synced directly with Supabase.
